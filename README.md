# College_Code

This repository is used to add codes aimed at my learning as a Programmer. All my codes will be posted so anyone can analyze and tell me what to improve.

## C Language

The C language codes are divided into two main categories:

- **Algorithms and Logic Programming:** These codes were developed based on exercises from the book "Algoritmos e Lógica de Programação" by José Augusto Manzano, as part of the Algorithms and Programming Techniques classes.

- **Data Structures:** This section contains implementations of data structures such as lists, stacks, and queues, created during the Data Structures course.

## Java Language

The Java language codes were created based on exercises conducted in Object-Oriented Programming classes.

## SQL Language

The SQL language databases are created based on classroom exercises, using MySQL Workbench.
